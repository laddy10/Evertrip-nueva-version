# Evertrip — The road is the thread

## Direction, before implementation

The previous page treated its hero, vehicle, destinations, fleet, and services as separate modules. The replacement is a continuous travel journal. Three moments carry the composition: a typographic coastal film; an interactive destination atlas; an oversized, original-photography fleet showroom. Booking remains available throughout.

Palette: deep Caribbean `#073B3A`, sea teal `#109B96`, salt paper `#F3F4EA`, navy ink `#0A1D31`, route yellow `#EBCB7A`. Yellow marks the journey, not every action. Outfit stays as the Evertrip voice, with an enlarged, tightly spaced display scale; Inter serves readable details.

```
  transparent navigation / compact model credit
  C A R I B E    [one complete, branded coastal film]
  scroll = moving camera, vehicle, road, and scenery together
          ~ route thread flows into the atlas ~
  destination names / active photograph / real route links
          ~ shoreline opens onto pale studio ground ~
  fleet names / full-size original vehicle photo / passenger count
  pickup → your journey → arrival / service links woven into story
  traveler voices / Instagram journal / FAQ / booking / signature
```

Composition alternates full bleed, wide editorial type, and quiet readable content. Text is primarily left aligned. No repeated card grid, floating vehicle overlay, independent background slideshow, or decorative infinite motion. The existing branded road film gives physically coherent tires, road contact, foreground occlusion, and lighting. Its imagery is an existing illustrative brand film, not a newly asserted documentary record of the route.

Review against the brief: a hero followed by redesigned cards would repeat the previous approach. This version therefore replaces the page composition and fleet interaction, uses the same route thread across transitions, and extends the design into destination and directory pages. Existing data, prices/quote rules, vehicle categories/capacities, ES/EN, gallery enlargement, route discovery, and WhatsApp remain authoritative.
